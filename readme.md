## 🇸🇦 العربية

### 📝 عن المشروع
**Modern Tech Store** هو تطبيق متجر إلكتروني حديث ومتجاوب لبيع المنتجات التقنية والأجهزة الإلكترونية. يتميز بتصميم أنيق وتجربة مستخدم سلسة لشراء أحدث الأجهزة الذكية والأكسسوارات.

- **رابط المعاينة المباشرة (Live Demo):** [https://omribrahim77.github.io/Tech-Store/](https://omribrahim77.github.io/Tech-Store/)

---

### ✨ المميزات الرئيسية
- 📱 **تصميم متجاوب:** يعمل بكفاءة عالية على جميع الشاشات (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).
- 🛍️ **تصفح المنتجات:** عرض الأجهزة والمنتجات التقنية بتصنيفات مختلفة.
- 🔍 **البحث والتصفية:** سهولة البحث عن المنتجات وتصفيتها حسب الفئة أو السعر.
- 🛒 **سلة التسوق:** إضافة وتعديل المنتجات داخل سلة الشراء.
- ⚡ **أداء سريع:** تحميل سريع للصفحات وتجربة تفاعلية.

### 🛠️ التقنيات المستخدمة
- **Front-end:** HTML5, CSS3, JavaScript
- **Styling:** Tailwind CSS / Bootstrap / Custom CSS
- **Deployment:** GitHub Pages
