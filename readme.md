## 🇸🇦 العربية

### 📝 عن المشروع
**Modern Tech Store** هو تطبيق متجر إلكتروني حديث ومتجاوب لبيع المنتجات التقنية والأجهزة الإلكترونية. يتميز بتصميم أنيق وتجربة مستخدم سلسة لشراء أحدث الأجهزة الذكية والأكسسوارات.

### 🔗 الروابط
- **رابط مستودع المشروع (GitHub Repo):** [https://github.com/omar77ibrahim11-creator/Modern-Tech-Store.git](https://github.com/omar77ibrahim11-creator/Modern-Tech-Store.git)
- **رابط المعاينة المباشرة (Live Demo):** `[ https://omribrahim77.github.io/Tech-Store/]`

---

### ✨ المميزات الرئيسية
- 📱 **تصميم متجاوب:** يعمل بكفاءة عالية على جميع الشاشات (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).
- 🛍️ **تصفح المنتجات:** عرض الأجهزة والمنتجات التقنية بتصنيفات مختلفة.
- 🔍 **البحث والتصفية:** سهولة البحث عن المنتجات وتصفيتها حسب الفئة أو السعر.
- 🛒 **سلة التسوق:** إضافة وتعديل المنتجات داخل سلة الشراء.
- ⚡ **أداء سريع:** تحميل سريع للصفحات وتجربة تفاعلية.

---

### 🛠️ التقنيات المستخدمة
- **Front-end:** HTML5, CSS3, JavaScript (أو React / Vue حسب البناء)
- **Styling:** Tailwind CSS / Bootstrap / Custom CSS
- **Deployment:** Vercel / GitHub Pages

---

### 🚀 كيفية التشغيل محلياً

1. **استنساخ المستودع (Clone):**
   ```bash
   git clone https://github.com/omar77ibrahim11-creator/Modern-Tech-Store.git
   ```

2. **الانتقال إلى مجلد المشروع:**
   ```bash
   cd Modern-Tech-Store
   ```

3. **تثبيت الحزم (إن وجدت):**
   ```bash
   npm install
   ```

4. **تشغيل المشروع:**
   ```bash
   npm start # أو npm run dev
   ```

## 🇬🇧 English

### 📝 About the Project
**Modern Tech Store** is a modern and fully responsive e-commerce web application for tech products and gadgets. It offers an intuitive user interface and a seamless shopping experience for browsing and purchasing the latest electronics.

### 🔗 Project Links
- **GitHub Repository:** [https://github.com/omar77ibrahim11-creator/Modern-Tech-Store.git](https://github.com/omar77ibrahim11-creator/Modern-Tech-Store.git)
- **Live Demo:** `[ https://omribrahim77.github.io/Tech-Store/]`

---

### ✨ Key Features
- 📱 **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
- 🛍️ **Product Catalog:** Display tech items with details and categories.
- 🔍 **Search & Filter:** Easily search products and filter by category or price.
- 🛒 **Shopping Cart:** Add, remove, and update quantities in the cart.
- ⚡ **High Performance:** Fast loading times and dynamic interactions.

---

### 🛠️ Tech Stack
- **Front-end:** HTML5, CSS3, JavaScript / React
- **Styling:** Tailwind CSS / Bootstrap / Modern CSS
- **Deployment:** Vercel / GitHub Pages / Netlify

---

### 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/omar77ibrahim11-creator/Modern-Tech-Store.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Modern-Tech-Store
   ```

3. **Install dependencies (if applicable):**
   ```bash
   npm install
   ```

4. **Run the project:**
   ```bash
   npm start # or npm run dev
   ```
